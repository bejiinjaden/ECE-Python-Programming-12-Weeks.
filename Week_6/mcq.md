# Week 6 MCQ: Loops

1. Which loop is used when the number of repetitions is known?
   A. for loop
   B. if loop
   C. while loop
   D. input loop

2. What does `range(1, 5)` produce?
   A. 1 2 3 4 5
   B. 1 2 3 4
   C. 0 1 2 3 4
   D. 1 2 3

3. Which keyword is used to repeat code while a condition is true?
   A. for
   B. while
   C. if
   D. elif

4. The loop below prints: `for i in range(3): print(i)`
   A. 1 2 3
   B. 0 1 2
   C. 3 2 1
   D. 0 1 2 3

5. A loop is used to:
   A. Store one value
   B. Repeat a task many times
   C. Compare two values
   D. Create a function

## Answers
1. A
2. B
3. B
4. B
5. B
