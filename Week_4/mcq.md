# Week 4 MCQ: Input and Output

1. Which function is used to display output in Python?
   A. input()
   B. print()
   C. echo()
   D. display()

2. What does `input()` return by default?
   A. Integer
   B. Float
   C. String
   D. Boolean

3. Which function converts a string to an integer?
   A. float()
   B. str()
   C. int()
   D. bool()

4. The code `print("Hello")` will display:
   A. Hello
   B. "Hello"
   C. Error
   D. None

5. Which statement is correct?
   A. print(input())
   B. input(print())
   C. display()
   D. output()

## Answers
1. B
2. C
3. C
4. A
5. A
