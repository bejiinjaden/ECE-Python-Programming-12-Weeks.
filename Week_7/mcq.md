# Week 7 MCQ: Strings

1. Which of the following is a string?
   A. 20
   B. True
   C. "hello"
   D. 3.5

2. What does `"Python".upper()` return?
   A. "python"
   B. "PYTHON"
   C. "Python"
   D. "PyThOn"

3. In Python, strings are enclosed in:
   A. Curly braces
   B. Square brackets
   C. Single or double quotes
   D. Parentheses

4. What is the index of the first character in a string?
   A. 1
   B. 0
   C. -1
   D. None

5. Which method removes spaces at the beginning and end of a string?
   A. split()
   B. strip()
   C. lower()
   D. replace()

## Answers
1. C
2. B
3. C
4. B
5. B
