# Week 8 MCQ: Lists and Tuples

1. Which of the following is a list?
   A. (1, 2, 3)
   B. [1, 2, 3]
   C. {1, 2, 3}
   D. "1, 2, 3"

2. A tuple is:
   A. Mutable
   B. Immutable
   C. Always a string
   D. A function

3. The index of the first element in a list is:
   A. 1
   B. 0
   C. -1
   D. None

4. Which statement adds an element to a list?
   A. append()
   B. add()
   C. insert()
   D. extend()

5. Which of these is valid Python syntax for a tuple?
   A. [1, 2, 3]
   B. {1, 2, 3}
   C. (1, 2, 3)
   D. <1, 2, 3>

## Answers
1. B
2. B
3. B
4. A
5. C
