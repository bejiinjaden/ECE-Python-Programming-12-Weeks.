# Week 12 MCQ: Exception Handling

1. What is the purpose of exception handling?
   A. To increase speed
   B. To manage errors safely
   C. To avoid variables
   D. To print text

2. Which keyword starts the error-handling block?
   A. except
   B. try
   C. finally
   D. error

3. Which keyword handles the exception?
   A. catch
   B. except
   C. when
   D. error

4. What happens if an error occurs in a `try` block and there is no matching `except`?
   A. The script continues normally
   B. The program crashes
   C. The code is ignored
   D. The variable is reset

5. Which error is raised when converting a non-numeric string to an integer?
   A. TypeError
   B. ValueError
   C. NameError
   D. KeyError

## Answers
1. B
2. B
3. B
4. B
5. B
