# Week 5 MCQ: Conditional Statements

1. Which keyword is used to start a condition in Python?
   A. loop
   B. if
   C. while
   D. print

2. What does `else` do?
   A. Adds a new variable
   B. Executes when the `if` condition is false
   C. Declares a function
   D. Stops the program

3. Which of the following is a comparison operator?
   A. =
   B. ==
   C. +
   D. %

4. What will the following code print? `if 8 > 5: print("Yes")`
   A. No
   B. Yes
   C. Error
   D. 5

5. `elif` is used when:
   A. You want to check another condition after `if`
   B. You want to print output
   C. You want to loop
   D. You want to define a function

## Answers
1. B
2. B
3. B
4. B
5. A
