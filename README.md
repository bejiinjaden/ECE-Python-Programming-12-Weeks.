# ECE Python Programming 12 Weeks

This repository is organized by week. Each week contains:
- a topic explanation
- one coding exercise
- one MCQ practice set

## Week Sequence
1. Week 1 - Variables
2. Week 2 - Data Types
3. Week 3 - Operators and Expressions
4. Week 4 - Input and Output
5. Week 5 - Conditional Statements
6. Week 6 - Loops
7. Week 7 - Strings
8. Week 8 - Lists and Tuples
9. Week 9 - Dictionaries and Sets
10. Week 10 - Functions
11. Week 11 - File Handling
12. Week 12 - Exception Handling

Each folder is aligned to a single topic, so students can practice both coding and multiple-choice revision together.
