# Week 11 MCQ: File Handling

1. Which function is used to open a file in Python?
   A. read()
   B. open()
   C. write()
   D. close()

2. Which mode is used to write data to a file?
   A. r
   B. w
   C. x
   D. a

3. What does mode `a` mean?
   A. Read only
   B. Write only
   C. Append data to the file
   D. Delete the file

4. After writing to a file, what should you do?
   A. Exit Python
   B. Close the file
   C. Restart the computer
   D. Rename the file

5. `read()` is used to:
   A. Delete a file
   B. Read the contents of a file
   C. Write new content
   D. Open the file in write mode

## Answers
1. B
2. B
3. C
4. B
5. B
