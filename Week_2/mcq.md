# Week 2 MCQ: Data Types

1. Which of the following is an integer value?
   A. "12"
   B. 12.5
   C. 12
   D. True

2. What type is `3.14`?
   A. int
   B. float
   C. str
   D. bool

3. Which of the following is a string?
   A. 100
   B. 3.2
   C. "Python"
   D. False

4. `True` and `False` are examples of:
   A. Strings
   B. Floats
   C. Booleans
   D. Lists

5. What does `type(5)` return?
   A. `<class 'float'>`
   B. `<class 'int'>`
   C. `<class 'str'>`
   D. `<class 'bool'>`

## Answers
1. C
2. B
3. C
4. C
5. B
