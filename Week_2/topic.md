# Week 2: Data Types

Python has several built-in data types, including:
- int: whole numbers
- float: decimal numbers
- str: text values
- bool: True or False

Examples:
```python
x = 10          # int
price = 19.99   # float
name = "Sam"   # str
is_active = True # bool
```

Understanding data types helps when performing operations and comparisons.
