# Week 9 MCQ: Dictionaries and Sets

1. A dictionary stores data in:
   A. Key-value pairs
   B. Single values
   C. Loops
   D. Strings

2. Which syntax creates a dictionary?
   A. [1, 2, 3]
   B. (1, 2, 3)
   C. {"name": "Ali"}
   D. "name": "Ali"

3. A set contains:
   A. Duplicate values
   B. Unique values
   C. Only numbers
   D. Only strings

4. To access a dictionary value, you use:
   A. Index number
   B. Key name
   C. Function name
   D. Loop counter

5. Which of the following is a valid set?
   A. {1, 2, 3}
   B. [1, 2, 3]
   C. (1, 2, 3)
   D. "1, 2, 3"

## Answers
1. A
2. C
3. B
4. B
5. A
