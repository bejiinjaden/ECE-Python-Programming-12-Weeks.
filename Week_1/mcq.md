# Week 1 MCQ: Variables

1. Which of the following is a valid variable name in Python?
   A. 1name
   B. student_name
   C. student-name
   D. class

2. What is the correct way to store the value 25 in a variable named age?
   A. age == 25
   B. age = 25
   C. int age = 25
   D. 25 = age

3. Which data type is assigned by the following code: `name = "Sara"`?
   A. Integer
   B. Float
   C. String
   D. Boolean

4. Which of these is a valid variable assignment?
   A. x + 5 = 10
   B. x = 10
   C. x == 10
   D. 10 = x

5. In Python, variable names are:
   A. Case-insensitive
   B. Always numeric
   C. Case-sensitive
   D. Not allowed to include underscores

## Answers
1. B
2. B
3. C
4. B
5. C
