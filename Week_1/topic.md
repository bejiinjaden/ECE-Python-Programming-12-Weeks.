# Week 1: Variables

Variables are containers used to store data in Python. A variable can hold a number, a string, or a boolean value.

Example:
```python
name = "Alice"
age = 20
is_student = True
```

Rules:
- A variable name must start with a letter or underscore.
- It cannot contain spaces.
- Python is case-sensitive.
- Variable names should be meaningful.

Practice idea: use variables to store user information and display it on screen.
