# Week 10 MCQ: Functions

1. A function is used to:
   A. Store a single value
   B. Repeat code without rewriting it
   C. Compare strings
   D. Define a class

2. Which keyword defines a function in Python?
   A. func
   B. define
   C. def
   D. function

3. A function can return:
   A. Only strings
   B. Only numbers
   C. A value
   D. Nothing at all

4. What does the `return` statement do?
   A. Prints the function name
   B. Sends a value back to the caller
   C. Starts a loop
   D. Creates a variable

5. Which of the following is a valid function call?
   A. def greet()
   B. greet()
   C. return greet
   D. print def

## Answers
1. B
2. C
3. C
4. B
5. B
