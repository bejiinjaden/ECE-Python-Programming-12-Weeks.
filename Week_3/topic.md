# Week 3: Operators and Expressions

Operators are symbols that perform actions on values.

Common operators:
- arithmetic: +, -, *, /, %
- comparison: ==, !=, >, <, >=, <=
- assignment: =, +=, -=

Example:
```python
a = 10
b = 3
print(a + b)
print(a > b)
```

Expressions combine variables and operators to produce a result.
