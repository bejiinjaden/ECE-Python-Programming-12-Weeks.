# Week 3 MCQ: Operators and Expressions

1. Which operator is used for addition?
   A. *
   B. +
   C. /
   D. %

2. What does `10 % 3` evaluate to?
   A. 3
   B. 1
   C. 0
   D. 10

3. Which operator compares whether two values are equal?
   A. =
   B. ==
   C. !=
   D. >

4. The expression `7 > 5` evaluates to:
   A. True
   B. False
   C. 7
   D. 5

5. Which statement correctly assigns a value?
   A. x == 10
   B. x = 10
   C. x + 10
   D. x != 10

## Answers
1. B
2. B
3. B
4. A
5. B
